# Fulcrum — Playtest

**[▶ Play in your browser](https://attic-games-development.github.io/Fulcrum-Playtest/)**

Nothing to download or install. It runs in the page.

Fulcrum is an organization management sandbox: you lead a small expeditionary
company from a wilderness camp, running expeditions in real time and managing
people, supplies, and logistics between them. This is an early prototype of the
first gameplay loop — expect rough edges. That's what you're here for.

## Telling us something

| Use this | When |
|---|---|
| [Something broke](../../issues/new?template=bug.yml) | Crash, freeze, or clearly wrong behavior |
| [How it felt](../../issues/new?template=feel.yml) | Nothing broke, but something felt off, confusing, or good |
| [I wish the game did...](../../issues/new?template=idea.yml) | A feature or change you'd like |

You'll need a free GitHub account to post. **Always include the Build ID** shown
in the bottom corner of the game screen — without it we often can't tell which
version you were playing.

"How it felt" reports are the most valuable kind. Bugs are easy for us to find
on our own; knowing that a stretch of the game is boring is not. Be blunt.

## What happens after you post

Reports are picked up automatically, usually within a few minutes. You may get
a reply asking a clarifying question — answering it genuinely helps, and it's
often the difference between a fix landing today or not at all.

Small fixes ship quickly. When one goes out, we'll come back and tell you on
your original report so you can check whether it actually solved your problem.
If it didn't, say so and we'll reopen it.

Ideas are read and considered but not implemented automatically — they get a
conversation first, since they have to fit where the game is trying to go.

## Two builds

- **stable** — the default link above. Use this one unless told otherwise.
- **preview** — updated continuously as fixes land. Rougher, but if you're
  working through a bug list with us, this is where your fix shows up first.

A build will never swap out from under you mid-session. When a new one is
available the game will say so, and you reload when you're ready to stop.

## A note on saves

This is an early prototype and the save format still changes. If a new build
can't read your old save the game will tell you rather than misbehave, but you
may lose that run. Sorry — it's the cost of moving this fast. If you're about
to do something long and deliberate, the stable build is the safer place.

## What's in this repository

Only the playable build and this issue tracker. The game's source code and
design documents live in a separate private repository.
